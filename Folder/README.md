# Roblox Phishing Campaign

## Overview
This is a phishing campaign that allows users to generate fake Roblox login pages, which they can use to collect victim data. The data is sent to both the user and admin dashboard.

## Features
- Clean, modern UI/UX
- Generator to create phishing pages
- Phishing page to collect user data
- Admin dashboard to monitor and broadcast data
- Dualhooked (user and admin webhooks)

## How to Use
1. Go to [GitHub Pages](https://pages.github.com/) or any static site host.
2. Upload the files to your site.
3. Test the phishing page and generator.
